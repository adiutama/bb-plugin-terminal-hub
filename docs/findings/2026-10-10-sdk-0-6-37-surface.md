# Do the brief's SDK facts hold on SDK 0.6.37?

- Date: 2026-10-10
- bb: 0.46.0
- Plugin SDK: 0.6.37

## Question

The brief's SDK facts came from SDK 0.4.47. Re-check them, plus the rail badge
(ADR 202610100906) and deep-link support, on the SDK the installed bb ships.

## Procedure

Read `bundled-types/bb-plugin-sdk.d.ts` and `bb-plugin-sdk-app.d.ts` from
`@get-bb/plugin-sdk@0.6.37`.

## Result

**Terminals (`TerminalsArea`)**: `list`, `create`, `get`, `input`, `output`,
`rename`, `restart`, `resize`, `close`, as the brief says. Changes and extras:

- `close` takes `mode: "force" | "if-clean"`.
- Sessions carry `threadId`, `environmentId`, `hostId`, `initialCwd`, `status`
  (`starting | running | exited | disconnected`), `exitCode`, `closeReason`,
  `createdAt`, `updatedAt`, `lastUserInputAt`.
- `output` takes `sinceSeq`, `tailBytes`, `limitChunks`; returns `chunks`,
  `nextSeq`, `truncated`.
- Still no "list all terminals" call; scopes are `thread`, `environment`,
  `host_path`.

**Push**: no terminal output stream and no terminal events. However,
`realtime.subscribe({ event: "thread:changed" })` delivers thread changes whose
`changes` can include `"terminals-changed"` (no terminal id). Whether it also
fires for environment-scoped terminals is not verified.

**Rail badge**: `PluginNavPanelRegistration` has no `badge`.
`experimental_sidebarAccessory` exists, but its doc says "no host surface
currently mounts it". `headerContent` renders in the page's title bar and is
mounted.

**`experimental_openTerminal({ terminalId })`**: "a plugin page [accepts] any
terminal". "Closing the tab closes the terminal." Resolves `false` for unknown
or exited terminals.

**Routing**: plugin pages live at `/plugins/<pluginId>/<path>/*` and receive the
rest as `subPath`; `useBbNavigate().toPluginPanel(path, { subPath, replace })`
navigates. `useBbContext()` gives `projectId` and `threadId` only; there is no
current-environment hook.

**Threads**: `threads.list({ environmentId, archived })`; thread `status` is
`active | error | idle | pending | starting | stopping`.

## Consequences

- ADR 202610100906 (rail badge) cannot be applied: proposed superseding ADR
  202610101629.
- ADR 202610100911 stands: output is still pulled. The `terminals-changed`
  signal can trigger list refreshes, with polling as the fallback.
- Deep links encode project, environment, and terminal in `subPath`.
- "Show in thread sidebar" (a later candidate in ADR 202610100905) is riskier
  than it looks: the tab it opens closes the terminal when closed.
