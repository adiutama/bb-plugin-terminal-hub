# Show a running-count badge on the rail entry

- Status: superseded
- Date: 2026-10-10
- Supersedes: none
- Superseded by: 202610101629
- Applies to: docs/specs/navigation.md (planned)

## Context

Users should see that something is running without opening the page.

## Decision

The Terminals rail entry shows the number of running terminals in the selected environment, if the host renders the badge.

## Consequences

One badge variant is documented as accepted but not mounted by the host. A finding must confirm a working variant; if none renders, this decision is superseded.
